Nombre de la aplicación: LEVEL FIT.
- Descripción de la aplicación: Una aplicación para deportistas que quieren seguir su progresó 
- Problema que busca solucionar: La falta de opciones propias que tiene un deportista para saber sus condiciones y avance por sus propios medios
- Público objetivo: Deportistas
- Objetivos del proyecto: Desarrollar una aplicación totalmente funcional para lograr ayudar a deportistas 
- Funcionalidades principales.
- Tecnologías utilizadas: Kotlin, XML, Android Studio y Firebase.
- Explicación de los cálculos que realiza la aplicación:
- Multiplicaciones para calcular peso realizado por ejercicio y peso total realizado

- Instrucciones de instalación

Instalación mediante APK
1. Descargar el archivo APK de LEVEL FIT.
2. Transferir el archivo a un dispositivo Android.
3. Permitir la instalación de aplicaciones de orígenes desconocidos, si el dispositivo lo solicita.
4. Abrir el archivo APK y presionar «Instalar».
5. Una vez finalizada la instalación, abrir LEVEL FIT.
Instalación mediante Android Studio
1. Clonar el repositorio:
   git clone https://github.com/MaxiSanta/LEVEL-FIT.git
2. Abrir el proyecto en Android Studio.
3. Sincronizar las dependencias de Gradle.
4. Conectar un dispositivo Android o iniciar un emulador.
5. Presionar el botón Run para compilar y ejecutar la aplicación.
Instrucciones de uso
1. Abrir la aplicación LEVEL FIT.
2. Crear una cuenta mediante el formulario de registro.
3. Iniciar sesión con las credenciales registradas.
4. Acceder al menú principal.
5. Seleccionar una rutina de entrenamiento.
6. Iniciar el entrenamiento e ingresar los datos de los ejercicios realizados.
7. Consultar los resultados de los cálculos.
8. Guardar el entrenamiento en Firebase.
9. Consultar los entrenamientos realizados desde el historial.
10. Cerrar sesión al finalizar.
